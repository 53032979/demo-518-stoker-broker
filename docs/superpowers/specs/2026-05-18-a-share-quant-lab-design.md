# A 股量化策略实验室设计规格

日期：2026-05-18

## 目标

构建一个本地 Web 策略实验室，用于快速验证 A 股量化策略。第一版重点是表单化策略、日线级回测和交易视角结果展示，让用户可以在一个页面内完成策略选择、参数调整、回测运行和结果判断。

第一版不是实盘交易系统，也不是完整因子研究平台。实盘、分钟级回测、研究视角因子分析作为后续扩展点保留。

## 第一版范围

第一版交付：

- 单页 Web 工作台，默认布局为左侧控制台、右侧结果区。
- 默认指数股票池：沪深 300、中证 500、中证 1000。
- 自定义股票池：支持输入或上传股票代码列表。
- 数据源：免费公开数据、本地 CSV/Parquet 上传；架构预留 Tushare Provider。
- 回测频率：日线级。
- 内置 5 个策略模板：低估值质量组合、动量 Top N、低波动组合、多因子综合打分、均线趋势过滤组合。
- 基础交易成本和约束：佣金、印花税、滑点、100 股最小交易单位、涨跌停无法成交。
- 交易视角结果页：核心指标、资金曲线、回撤曲线、K 线买卖点、当前持仓、交易流水、运行日志。
- API、后端计算和核心回测逻辑具备自动化测试覆盖。

第一版不交付：

- 实盘交易、模拟盘下单、券商接口。
- 分钟级回测和日内撮合。
- T+1、停牌、ST、退市、新股过滤、部分成交等更完整 A 股约束。
- IC、Rank IC、因子分层收益、行业暴露、参数网格搜索等研究视角模块。
- 任意 Python 代码策略编辑器。

## 技术方案

采用轻量 Web 策略实验室方案：

- 前端：React + ECharts/Plotly。
- 后端：FastAPI。
- 计算层：Python + Pandas/Polars。
- 存储层：DuckDB + Parquet。
- 回测内核：自研日线事件驱动回测内核。

选择该方案的原因：

- 页面体验可控，适合做一个高频使用的单页工作台。
- 策略库、数据上传、回测结果和图表交互可以围绕当前工作流设计。
- DuckDB + Parquet 对本地研究数据足够轻量，也便于后续迁移。
- 自研日线内核能控制 A 股交易成本和约束的实现细节，避免被通用框架限制。

## 工作台设计

默认采用左侧控制台 + 右侧结果区。

左侧控制台包含：

- 策略模板选择。
- 股票池选择：沪深 300、中证 500、中证 1000、自定义股票池。
- 数据源选择：免费数据、本地上传、Tushare 预留。
- 回测参数：日期范围、调仓周期、持仓数量、因子权重、止盈止损、佣金、印花税、滑点。
- 运行按钮。
- 数据校验和运行状态提示。

右侧结果区包含：

- 顶部指标卡：总收益、年化收益、最大回撤、夏普、胜率。
- 主图区域：资金曲线、回撤曲线、K 线买卖点。
- 下方表格：当前持仓、交易流水、运行日志。

## 数据源设计

第一版支持三类数据入口：

- 免费公开数据源：优先用于快速跑通默认指数股票池和日线行情。
- 本地上传：支持 CSV 和 Parquet，适配用户从合法渠道导出的行情、指数成分、财务和因子数据。
- Tushare Provider 预留：先定义 provider 接口和 token 配置位置，第一版不强依赖 Tushare 权限。

同花顺/iFinD 相关数据只支持合法方式：

- 支持导入用户从同花顺/iFinD 官方接口或终端合法导出的文件。
- 不实现绕过登录、验证码、付费限制、反爬限制或服务条款的爬虫。
- 若后续实现采集器，只允许采集明确允许访问的公开数据，并包含限速、缓存、来源记录和失败退避。

## 本地上传校验

上传 CSV/Parquet 后执行：

- 字段映射检查。
- 日期标准化。
- 证券代码标准化。
- 必填字段检查。
- 缺失值检查。
- 重复行检查。
- OHLC 价格合法性检查。
- 数据覆盖范围统计。
- 股票池有效标的数量检查。

校验失败时不写入正式数据表，前端显示具体失败原因和建议修正方式。

## 策略库设计

策略库按三层组织。

### 多因子

第一版支持：

- 价值：PE、PB、股息率。
- 动量：近 N 日收益。
- 质量：ROE、毛利率、负债率。
- 低波动：收益波动率。
- 流动性：成交额、换手率。

因子处理第一版保持简单：

- 支持升序/降序排名。
- 支持因子权重。
- 支持缺失值剔除。
- 支持 Top N 选股。

因子去极值、标准化、中性化、IC 和分层收益进入后续研究视角。

### 经典选股模板

第一版内置：

- 低估值质量组合：低 PE/PB + ROE 或毛利率过滤。
- 动量 Top N：按近 N 日收益排名选择 Top N。
- 低波动组合：按历史收益波动率选择低波动标的。
- 多因子综合打分：价值、质量、动量、低波动、流动性加权评分。
- 均线趋势过滤组合：在选股结果上叠加 MA20/MA60 趋势过滤。

### 买卖规则

第一版支持：

- 周、月、季度调仓。
- Top N 持仓。
- 等权配置。
- 因子分权重。
- 均线过滤。
- N 日突破。
- 止盈、止损、移动止损。

## 回测规则

第一版按日线事件驱动实现：

1. 按交易日推进。
2. 在调仓日根据策略模板生成目标股票列表和目标权重。
3. 根据目标权重和账户权益生成订单。
4. 按日线价格模拟成交。
5. 扣除佣金、印花税和滑点。
6. 应用最小交易单位 100 股。
7. 对涨跌停无法成交的订单记录失败原因。
8. 更新现金、持仓、市值、权益曲线。
9. 输出交易流水、持仓快照、指标和日志。

第一版交易成本参数：

- commission_rate：佣金率。
- stamp_tax_rate：卖出印花税率。
- slippage_bps：滑点，单位 bps。
- min_lot_size：默认 100 股。

后续补充：

- T+1 卖出约束。
- 停牌处理。
- ST、退市、新股过滤。
- 调仓失败和部分成交。
- 更精细的涨跌停和成交量约束。
- 分钟级撮合。

## API 设计

### /data

职责：

- 上传 CSV/Parquet。
- 触发免费数据导入。
- 查询数据覆盖范围。
- 查询导入任务状态。

关键接口：

- POST /data/uploads
- GET /data/coverage
- GET /data/import-jobs/{job_id}

### /pools

职责：

- 查询默认指数股票池。
- 创建自定义股票池。
- 校验股票池代码。

关键接口：

- GET /pools
- POST /pools
- POST /pools/validate

### /strategies

职责：

- 查询策略模板。
- 查询参数 schema。
- 查询默认参数。

关键接口：

- GET /strategies
- GET /strategies/{strategy_id}
- GET /strategies/{strategy_id}/schema

### /backtests

职责：

- 创建回测任务。
- 查询运行状态。
- 查询回测结果。
- 查询运行日志。

关键接口：

- POST /backtests
- GET /backtests/{run_id}
- GET /backtests/{run_id}/status
- GET /backtests/{run_id}/results
- GET /backtests/{run_id}/logs

## 错误处理

错误分为三类。

### 数据错误

示例：

- 缺少必填字段。
- 日期格式错误。
- 股票代码无法识别。
- 行情数据缺失。
- 重复数据。
- 股票池没有有效标的。

前端展示：

- 错误类型。
- 出错字段或数据范围。
- 可操作修正建议。

### 策略错误

示例：

- 参数越界。
- 因子字段不可用。
- 调仓日无法生成有效持仓。
- 持仓数量大于有效股票数量。

前端展示：

- 参数项定位。
- 策略模板名称。
- 失败原因。

### 运行错误

示例：

- 数据源失败。
- 回测任务超时。
- 结果为空。
- 后端计算异常。

前端展示：

- 任务状态。
- 简短错误摘要。
- 详细日志入口。

- 股票池解析和校验。

- 最小交易单位处理。
- 涨跌停无法成交。

前端测试覆盖：

- 股票池选择和自定义股票池输入。
- 上传数据成功、失败、空状态。
- 回测运行状态。
- 结果图表和表格展示。
- 错误状态展示。

## 验收标准

第一版完成时，用户应能：

1. 打开本地 Web 工作台。
2. 选择沪深 300、中证 500、中证 1000 或自定义股票池。
3. 选择 5 个内置策略模板之一。
4. 修改策略参数、交易成本和回测区间。
5. 运行日线级回测。
6. 查看总收益、年化收益、最大回撤、夏普、胜率。
7. 查看资金曲线、回撤曲线、K 线买卖点。
8. 查看当前持仓、交易流水和运行日志。
9. 上传 CSV/Parquet 并看到明确的数据校验结果。
10. 在数据或策略配置错误时看到可读、可操作的错误提示。

## 后续路线图

优先级较高：

- 研究视角：IC、Rank IC、因子分层收益、行业暴露、换手、参数对比。
- A 股真实交易约束：T+1、停牌、ST、退市、新股、调仓失败。
- Tushare Provider：token 配置、接口权限检测、数据缓存。
- 本地数据管理：数据版本、来源审计、增量更新。

优先级中等：

- 分钟级数据 schema 和回测撮合。
- 参数网格搜索。
- 策略结果对比。
- 回测报告导出。

暂不优先：

- 实盘交易。
- 自动下单。
- 任意 Python 代码策略编辑器。

## 外部资料记录

Tushare Pro：

- 注册后在个人中心获取 token。
- API 权限与积分和独立权限相关。
- 日线、分钟线、实时数据和部分高级数据权限不同。
- 第一版只预留 Provider，不强依赖用户已有 Tushare 权限。

同花顺/iFinD：

- 支持合法导出的文件导入。
- 不实现绕过访问限制的数据抓取。
- 若使用官方 QuantAPI/iFinD，应作为正式数据 Provider 接入。

经典策略资料方向：

- Fama-French 三因子和五因子模型。
- Jegadeesh-Titman 动量框架。
- 低波动、价值、质量、流动性等经典因子。
- A 股市场中的因子有效性和因子动量研究。

## 开放假设

- 第一版运行在本地单用户环境，不做登录和多用户权限。
- 默认数据规模以日线级指数成分股回测为目标。
- 免费数据源可能不稳定，系统必须允许本地上传数据替代。
- 结果展示优先服务交易判断，研究视角后续补齐。
